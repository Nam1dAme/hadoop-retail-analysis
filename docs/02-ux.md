# 02 页面与交互

UBA-DOC-1.0.0 / FROZEN。

统一顶部显示release、源窗口、策略版本、数据规模、更新时间；各页请求显式携带同一个release_id。日期选择显示“结束日期不含”，默认整个观察窗口。预测页使用固定as_of，不能把分析日期筛选套到训练标签上。新版本出现只提示，不在一组查询中自动切换。

| 页面 | 内容与交互 |
|---|---|
| 行为总览 | pv/buy/cart/fav记录数、窗口UV、每日趋势、小时热力图；明确buy不是订单 |
| 商品与类目 | 分类型事件数排行、ID搜索、日趋势；排行默认pv，允许切换；无名称时只显示ID |
| 用户活跃 | 日UV、首次观察用户、次日复访率、浏览用户购买比例；显示分母及不可观察日期 |
| 行为预测 | TEST回溯/未来评分两种模式；模型选择、用户ID查询、分数排序；as_of与预测窗口固定展示 |
| 模型实验 | 三算法指标、样本数/正例率、训练曲线、阈值、测试封存说明、CUDA与CPU对照及资源峰值 |
| 数据质量与任务 | 原始/拒绝/窗口内外行数、重复候选、时间异常、YARN application ID、重试和日志摘要 |
| 版本与方法 | 版本列表、当前版本、数据来源、指标定义、局限、报告下载入口；无发布/训练按钮 |

预测表字段user_id、model、as_of、window_end、score、predicted_positive、label_status、observed_label（仅TEST）、history_event_count。未来评分必须显示“未观察到目标日结果，非已验证准确率”；不显示虚构日期后的真实行为。

数值0与无数据分开：分母0返回null并显示“无可计算样本”；错误不得渲染成0。类别缺失、数据拒绝和窗口外数据在质量页解释。无发布版本显示引导说明；无用户历史返回无预测记录，不随机生成分数。模型失败显示明确状态，不伪装成简单模型结果。

列表最大每页100；稳定游标翻页；用户精确检索，不提供全量行为下载。窄屏表格横向滚动。颜色不能成为唯一含义，图表提供单位、图例与文本统计。模型分数标为估计分数；LOGISTIC/GRU不同分数不直接解释为同等真实概率。

演示路径：质量与全量计数 → YARN真实作业 → 行为/活跃分析 → 时间切分 → CUDA训练曲线 → 三模型对照 → 未来评分 → 发布与恢复证据。
