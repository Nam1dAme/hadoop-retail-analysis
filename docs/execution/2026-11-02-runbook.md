# 本机运行与验收手册

本文件补充冻结基线，不修改其验收要求。运行目录为`/home/hadoop/hadoop-retail-analysis`。没有另一块物理磁盘；任何本机备份成功或恢复成功都不能记作独立介质备份通过。

## 启动和查看

```bash
cd /home/hadoop/hadoop-retail-analysis
source scripts/dev-env.sh
python scripts/database-service.py start
scripts/hadoop-service.sh start
python scripts/web-service.py start
python scripts/web-service.py status
```

页面为`http://127.0.0.1:8510`，API为`http://127.0.0.1:8010`；HDFS、YARN、HistoryServer页面分别为19870、18088、19888。所有地址均为本机回环。WSL重新启动后运行上述命令；不要对已有HDFS再次格式化。代码升级后重启web服务以载入新的API进程；日常查看结果不执行训练或pipeline。

GPU使用`/usr/lib/wsl/lib/nvidia-smi`检查。Codex沙箱内缺少GPU设备或socket访问权限，与WSL宿主是否有GPU是两件事。正式CUDA及数据库探针应在获准访问设备/本机服务的执行环境运行，证据以实际探针为准。

## 已有结果与幂等恢复

完整来源为`var/data/UserBehavior.csv`。模型正式实验、样本、评分和发布索引分别位于`var/production/models.json`、`samples.json`、`forecast.json`、`release.json`；索引文件缺失不表示对应阶段已经成功。

```bash
# 以下为正式验收入口；只在没有其他重任务时串行执行。
python scripts/verify-models.py
python scripts/publish-results.py forecast
python scripts/publish-results.py publish
python scripts/verify-release.py
```

模型训练已有完整结果时无需重新训练。确需恢复未完成实验才执行`python scripts/train-models.py`；它核验同一实验与检查点，不允许把其他权重冒充原训练。发布装载中断后重新执行publish，依据STAGING装载游标续装；不得手改`rows_loaded`或把STAGING改为READY。发布前的全部校验通过后才更新current。

发布回滚命令为`python scripts/publish-results.py rollback --release-id <READY版本UUID> --expected-generation <当前generation>`。generation用于并发保护；只可选择完整READY版本。不要直接修改current表，也不要删除旧版本依赖。

## 本机备份与恢复

```bash
python scripts/backup-release.py
python scripts/restore-backup.py
```

备份创建压缩归档和文件摘要清单，包含发布依赖及数据库一致性快照；不包含凭据。恢复使用独立3308端口、独立数据库目录及`/behavior-recovery`根，核验逐文件摘要、表行数及同版本API结果。成功后只删除本次创建并验证的恢复临时目录，保留压缩备份；失败保留日志供定位。

本机恢复RTO验收目标为4小时。实际结果见`var/production/backup.json`和`recovery.json`，未产生报告前不得声称通过。若将来获得独立介质，需要复制压缩归档及清单、重新核验摘要，并从该介质执行恢复后再单独验收。

## 空间与故障处理

新重任务至少保留20GiB启动余量，运行中低于10GiB终止；全量阶梯采用120GiB保守预留，或依据实测1000万阶段增量峰值按行数放大、乘1.5并加20GiB计算准入。宿主空间不足时停止启动任务，不能靠WSL内部显示的大余量推断宿主仍有空间。

运行`python scripts/retention-plan.py`生成只读引用保护计划，不执行删除。该工具保守保留全部READY/STAGING依赖与所有源归档；实际清理仍须重新核查引用与活动任务。至少保留current、上一完整版本及其依赖；未有已验证备份不得删除唯一源归档。失败临时目录7天、任务日志30天是保留策略，仍须检查活动任务和引用闭包才能清理。本手册不提供绕过引用保护的宽泛删除命令。

任务失败查看`var/production/runs/<run_id>/driver.log`及阶段stderr；锁冲突先核实原PID和启动时间、实际YARN应用终态，不能因等待时间长就重复提交或杀其他项目进程。数据库账号分别为控制writer、结果loader、只读reader及DDL migrator；凭据只从权限0600文件读取，不复制进命令、文档或提交。
