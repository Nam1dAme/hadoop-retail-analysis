# 工作台交互与边界修复

## 设计方向（frontend-design）

沿用旧工作台的蓝白分析工具风格。主蓝#3159D6、深墨#1D2B45、页面底#F2F5FA、纸白#FFFFFF、选中浅蓝#EAF0FF、边线#E1E8F1。数字继续使用本地IBM Plex Sans子集，中文继续使用本地Noto Sans SC子集。

布局：固定宽度侧栏承载七个页面，主内容区随可用宽度伸缩；窄屏侧栏以抽屉展开，短屏侧栏内部纵向滚动。文字左对齐，长版本号允许换行，表格在自身区域内横向滚动。

```
宽屏：| 238px 导航 | 标题、版本与查询条件 / 数据和图表 |
窄屏：| 展开导航  | 当前页面                         |
      | 抽屉内导航、关闭按钮；主页面独立滚动         |
```

悬停只改变颜色，几何尺寸保持稳定；选中、悬停、按下与键盘焦点均使用蓝色体系。关闭按钮始终保留布局空间并可见。保留键盘焦点和减弱动态效果支持。

方案复查：遵循旧项目已有视觉方向，将改动集中在侧栏、文字边界和控件状态；以真实交互验证代替静态截图推断。

## 已复现问题

1. 1440px宽真实浏览器中，侧栏折叠按钮由display:none变为inline；全局按钮38px最小高度使头部从78px变为84px，整列下移6px。
2. 次要按钮悬停文字与边框为rgb(255,75,75)，来自未覆盖的Streamlit默认主题。
3. 侧栏说明段落继承默认正文尺寸，长说明、长版本号和内部Flex容器需要分别约束，不能只检查document.scrollWidth。

验收将覆盖全部七页、宽屏/中屏/窄屏、侧栏展开/关闭、逐项悬停、键盘焦点、按钮颜色和容器内部边界。
