# Repository conventions

- Use Conventional Commits with an English type and scope, followed by a Chinese description: `type(scope): 中文描述`.
- Keep technical identifiers in their original form when needed, for example `fix(data): 将源数据集迁移至项目本地目录`.
- Choose an appropriate type such as `feat`, `fix`, `docs`, `test`, `build`, `perf`, `refactor`, or `chore`.
- Keep each commit focused on one logical change.
- Keep raw datasets, credentials, caches, and generated artifacts out of Git.
